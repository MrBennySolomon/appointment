# סטודיו לציפורניים – מערכת תורים (React + Vite)

```
npm install
npm run dev      # פיתוח מקומי
npm run build    # בנייה לקבוצת קבצים להעלאה (תיקיית dist)
```

חיבור ל-mockapi.io: מעתיקים את `.env.example` ל-`.env` וממלאים `VITE_API_URL`.
בלי ערך, האתר עובד במצב הדגמה (שמירה בדפדפן בלבד).

שדות המשאב `bookings`: slot, name, phone, service, label (טקסט) ו-ts (מספר).
